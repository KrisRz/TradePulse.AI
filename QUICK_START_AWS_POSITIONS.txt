❓ TROUBLESHOOTING
──────────────────

Q: Still shows "using DynamoDB Local"?
A: Make sure DYNAMODB_ENDPOINT is not set:
   unset DYNAMODB_ENDPOINT

Q: AWS credentials not loading?
A: Verify the file exists:
   cat /Applications/Projects/TradePulse.AI/Kris_accessKeys.csv
   (Should show Access Key ID and Secret on line 2)

Q: API returns empty list?
A: AWS credentials may lack DynamoDB read permissions, or 
   position_results table may not exist.
   Run: bash test_closed_positions_aws.sh

Q: Need to switch back to local DynamoDB?
A: Just make sure Kris_accessKeys.csv is not readable, or manually set:
   export AWS_ACCESS_KEY_ID=dummy
   export AWS_SECRET_ACCESS_KEY=dummy
   export DYNAMODB_ENDPOINT=http://localhost:8000

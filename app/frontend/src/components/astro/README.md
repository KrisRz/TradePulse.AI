# Astro Components

## Overview
Server-side rendered Astro framework components used for static site generation and landing pages. These are .astro files that handle SSR and static content.

## Components

### Features.astro
- **Purpose**: Feature showcase component for landing pages
- **Features**: Product feature highlights, benefit displays

### Footer.astro
- **Purpose**: Site footer component
- **Features**: Footer links, company information, social links

### Header.astro
- **Purpose**: Site header component
- **Features**: Navigation, branding, user menu

### Hero.astro
- **Purpose**: Hero section component for landing pages
- **Features**: Main call-to-action, hero content, value proposition

### Stats.astro
- **Purpose**: Statistics display component
- **Features**: Key metrics display, performance statistics

## Usage
These components are typically imported directly in .astro files:
```astro
---
import Hero from '../components/astro/Hero.astro';
import Features from '../components/astro/Features.astro';
---
```

## Framework
- Built with Astro framework
- Server-side rendered (SSR)
- Optimized for static site generation
- Used in marketing and landing pages

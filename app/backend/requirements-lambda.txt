# Paper-bot Lambda runtime dependencies — EXACT pins, no ranges.
#
# Why a separate file: the bot's zip carries only the dependency-light packages
# it actually imports. numpy/pandas come from the AWS managed
# AWSSDKPandas-Python311 layer; boto3/botocore from the Lambda runtime itself.
# Installing either into the zip shadows the layer/runtime copy and breaks it.
#
# Why exact pins: `scripts/build_lambda_package.sh` rebuilds this zip on every
# deploy. An unpinned install silently ships whatever PyPI serves that day into
# a bot that trades — the build must be reproducible, and the version that runs
# in production must be the version we validated.
#
# These are the versions verified live in the eu-west-2 deployment
# (CodeSha256 r8LuxnoJgluluwOEuPP6tk5nRDrhpjNq4emap/stNq0=, deployed 2026-07-22).
# Bumping any of them = rebuild + `terraform apply` + re-verify the hash.
